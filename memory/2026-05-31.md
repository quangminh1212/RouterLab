   - POST /a2a (JSON-RPC: message/send, message/stream, tasks/get, tasks/cancel)
   - GET /api/a2a/status, /api/a2a/tasks, /api/a2a/tasks/:id, POST .../cancel
2. OpenAI-compatible Batch API (/v1/batches) + minimal Files API (/v1/files)
   - No "batches" / "completion_window" anywhere in repo (confirmed via grep)
   - No ".well-known" / "a2a" / "jsonrpc" anywhere (confirmed via grep)
